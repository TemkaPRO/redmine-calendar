# Redmine календарь

Маленькая программа для Windows: берёт из Redmine открытые задачи, назначенные на меня, и раскладывает их по срокам.

- **План по дням**: просрочено → сегодня → завтра → следующие 7 дней → позже → без срока. В каждой группе сначала задачи с более высоким приоритетом, рядом сумма часов.
- **Неделя**: колонки по дням. Хвосты с прошлых недель вынесены отдельной полосой сверху.
- **Месяц**: календарь, клик по дню показывает его задачи справа.
- Слева сводка (просрочено / сегодня / завтра / 7 дней) и загрузка на сегодня относительно рабочего дня.
- **Чьи задачи**: слева переключатель «Мои задачи» / каждый сотрудник / «Вся команда». Команда настраивается в «Настройки → Команда»: можно выбрать из подсказок (люди, которым ты ставишь задачи) или добавить по ссылке на профиль.
- **Карточка задачи** (клик по задаче):
  - смена проекта (поиск по названию), статуса, трекера, исполнителя, срока и готовности, комментарий (Ctrl+Enter), всё уходит в Redmine одной записью;
  - у каждого сотрудника команды есть «личный проект»: проект с его фамилией или тот, где больше всего его задач. Если назначить задачу на сотрудника, она сама переедет в его проект. Если назначить на человека не из команды, проект остаётся тем, что выбран в поле «Проект». После сохранения появляется сообщение вида «#123 переведена в проект «…» на …»;
  - при смене проекта списки трекеров и участников берутся из нового проекта. Если текущего трекера там нет, программа подставит другой и предупредит об этом;
  - история изменений и комментариев;
  - кнопка «В работу» запускает таймер и ставит статус «В работе», если workflow его разрешает;
  - «Стоп» открывает окно записи времени: время в формате Ч:ММ (`0:24`, `1:24`; таймер подставляет минуты с округлением вверх), дата, деятельность, комментарий; принимаются также `1,5` (часы) и `90м` (минуты);
  - кнопка «Записать время» позволяет внести трудозатраты вручную.
- **Перенос срока перетаскиванием**:
  - в «Плане» задачу можно бросить на заголовок дня, в «Неделе» на колонку, в «Месяце» на ячейку;
  - пока тащишь, внизу появляется панель «Сегодня / Завтра / +1 день / +1 неделя / +1 месяц / Без срока»;
  - если подержать задачу над стрелками ◀ ▶, неделя или месяц перелистнутся;
  - после переноса 8 секунд доступна кнопка «Отменить»;
  - если новый срок раньше даты начала, дата начала сдвигается вместе с ним.
- **Описание и комментарии показываются с оформлением Redmine (Textile).** Поддерживаются:
  - жирный и курсив, `@код@`;
  - ссылки `"текст":url`, ссылки на задачи `#12345` (открываются тут же);
  - заголовки, списки `#`/`*`, таблицы, `<pre>`;
  - `{{collapse(...)}}` и картинки `!файл.png!` из вложений.

  Файлы задачи перечислены под описанием, программа берёт их из Redmine по твоему API-ключу.
- **Новая задача:** кнопка «+ Задача» вверху или клавиша `N`. Поля:
  - проект с поиском, тема, трекер, приоритет;
  - исполнитель (по умолчанию тот, чьи задачи открыты);
  - срок, начало, оценка в формате Ч:ММ, родительская задача;
  - обязательные поля проекта.

  Описание можно посмотреть во вкладке «Просмотр». Кнопка «Вставить шаблон бага» добавляет шаги, ОР и ФР. В карточке задачи кнопка «Подзадача» создаёт задачу с этой родительской.
- Таймер хранится в `%APPDATA%\RedmineCalendar\timer.json`, поэтому переживает закрытие окна и перезагрузку компьютера.
- Поиск, фильтр по проекту, светлая и тёмная тема.
- Горячие клавиши: `1` `2` `3` переключают вид, `/` ставит курсор в поиск, `R` обновляет задачи, `F5` перезагружает окно, `←` `→` листают неделю или месяц, `Esc` закрывает окна.

## Запуск

Двойной клик по `redmine_calendar.pyw`. Нужен Python 3.10+ и Edge (или Chrome), сторонних библиотек нет.

Как устроено: Python поднимает локальный сервер на `127.0.0.1:47823` и открывает Edge в режиме приложения, то есть отдельным окном без адресной строки. В Redmine ходит только сервер, API-ключ в окно не передаётся. Закрыл окно — сервер завершился сам.

При первом запуске откроются настройки:
1. **Адрес Redmine**, например `https://redmine.company.ru`.
2. **API-ключ**: в Redmine «Моя учётная запись» → справа «Ключ доступа к API» → «Показать».
3. «Проверить связь» → «Сохранить».

Посмотреть на выдуманных задачах:

```
python redmine_calendar.pyw --demo
```

## Доступ с телефона

Включается в «Настройки → Доступ с телефона»:
1. Включи «Разрешить вход с телефона», задай PIN или пароль (минимум 6 символов) и при желании порт (по умолчанию 47824).
2. Программа покажет адрес вида `http://192.168.1.10:47824/`. Открой его на телефоне и введи PIN.
3. Чтобы открывалось как приложение, в меню браузера выбери «Добавить на главный экран».

Как это устроено:
- **Вход:** по PIN, телефон запоминается на 30 дней. После 5 неверных попыток с одного адреса (или 30 за час всего) вход блокируется на 15 минут. Вошедшие телефоны видны в настройках, там же их можно отключить. Новый PIN отключает все телефоны.
- **Ограничения:** с телефона нельзя поменять адрес Redmine, API-ключ, команду и PIN.
- **Работа в фоне:** пока доступ включён, программа работает и после закрытия окна. При автозапуске с Windows она стартует тихо, без окна.
- **Сеть:** телефон и компьютер должны быть в одной сети: Wi-Fi, VPN или Tailscale. Внутри сети трафик идёт по HTTP.

На телефоне:
- нижние вкладки «План / Неделя / Месяц / Люди / Ещё»;
- сверху счётчики и таймер;
- неделя показана списком по дням;
- в месяце у каждого дня счётчик задач;
- срок переносится кнопками «Срок: Сегодня / Завтра / +1 неделя / +1 месяц / Без срока» в карточке задачи. Эти же кнопки есть и на компьютере.

## Где что лежит

- `web/index.html`: интерфейс.
- Настройки (в том числе API-ключ, открытым текстом): `%APPDATA%\RedmineCalendar\config.json`
- Профиль окна Edge: `%APPDATA%\RedmineCalendar\window`
- Автозапуск: `%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\RedmineCalendar.vbs`. Включается галкой в настройках.

Если Redmine отвечает 403, значит в нём выключен REST API. Его включает админ: «Администрирование → Настройки → API».
